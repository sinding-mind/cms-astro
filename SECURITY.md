# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on
https://github.com/sinding-mind/cms-astro (a private security advisory).

Include the version of `@sindingmind/cms-astro`, the Astro version, and how to reproduce the problem. We aim to
answer within five working days and will tell you when a fix is released. We credit reporters who want it.

## Supported versions

Only the latest published version gets security fixes.

## Scope

This repository holds the open Astro integration only. Problems in the closed Sinding Mind editor service can be
reported the same way.
